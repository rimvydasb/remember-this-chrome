design proposal · v2

Graphite

A solid, dynamic workspace for the library. Dark by default, monospace for data, one indigo accent. The whole width goes to content: no inspector column and no status bar. AI state lives in one header control that opens a detailed panel.

01Collapsible filtersA Filters button opens a panel above the list; each group folds on its own. Chosen filters always show in a fixed “Active” section below.
01bCollapsible sidebarFolds to an icon rail; catalogs keep letter badges.
01cAligned sub-headerOne 48 px band across all columns with a single straight bottom line.
10Grid & spacing system4 px base unit, a 16 px gutter, four radii and fixed control heights, used everywhere.
01dPlain transcriptPlain paragraphs, no timestamps, exactly as stored and sent to the AI.
02Local AI panelA header pill shows AI state and progress; click it for server, model, queue and controls.
03Tag chips unchangedSame colors and icons as the app today: mood colors, category icons, red channel, navy topics.
04No inspectorFacts, sentiment, chapters and links are part of the main column.
05Settings & prompt editorPrompt editor with line numbers, field palette, validation, live preview and diff against the default.
06Bookmark + star iconIndigo tile, flat colors, proportions tuned per size.
07Sections, not tabsSummary, sentiment, questions, related, details and transcript are stacked sections that fold.
08Theme & settings placementTop-right of the header, marked with pins below.
09No footer barContent runs to the bottom of the window.

The gutter is 16. Text and control edges start 16 from a column edge. When a row ends with an icon button, the padding is 8, so the glyph inside it also lands on 16. The search box starts exactly where the list column starts.

App icon

Indigo tile, white bookmark, star cut out. Flat colors, rounded corners, a soft shadow under the bookmark at 48 px and up. The bookmark gets relatively smaller as the icon gets smaller (68 % of the tile height at 128 px, 58 % at 16 px), so the tile still reads as a tile in the toolbar.

Tag chips

Unchanged from the app: the icon shows the kind of sentiment, the color shows the mood (green → lime → gray / yellow → orange → red). Channels are red with a person icon; topics are navy. A filled chip is an active filter.

AI pill (header, right) — dot color = state; text = current job. Click to open the AI panel.
Sun / moon (header, right) — one click switches light ↔ dark. “Follow system” is in Settings → Appearance.
Gear (header, right) — opens the Settings dialog. Shortcut ,
⋯ menu (header, far right) — the actions that exist today: Import JSON, Export JSON, Export all as Markdown, Clear library. Click it.
Filters (list, top left) — opens and closes the filter panel (F). Chosen filters show in the Active section below it.
Sidebar button (sidebar, top right) — folds the sidebar to a 48 px icon rail ([). Catalogs keep a letter, so they stay distinct; hover shows the name and count.

Aligned sub-header. The first row under the header is one band, 48 px high, in all three columns: Library + collapse, Filters + count + sort, and breadcrumb + item actions. Their bottom lines form one straight line; nothing wraps onto a second row.

Filters: closed and open

The Filters row never changes height. Chosen filters go to the Active section under it: not collapsible, so you always see what is filtered, whether the panel is open or closed. Each chip removes its filter; “Clear all” removes all. Open, each filter group can fold; “any of” and “all of” are written next to the group name.
